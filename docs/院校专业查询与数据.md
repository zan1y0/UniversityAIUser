# 院校专业查询与数据

登录后进入「智能择校 → 查询院校专业」，填写年份及可选条件，再点「查询」。结果表在筛选区下方。可用 `2027 + 上海 + 计算机` 查看上交大统考计划，或用 `2026 + 江苏 + 计算机 + 350 分` 查看东南大学复试线。参考分数会排除高于所填分数的已知复试线，未收录复试线的记录仍保留并标明缺失。

数据在 `programs` 表。它是项目现有的 JSON 聚合表：物理列为 `id`、`owner_id`、`version`、`payload`、`created_at`、`updated_at`；公共院校数据的 `owner_id` 为 `public`。一条记录表示一所院校的某院系、某专业、某招生年份，学校与专业当前没有拆成独立表。

## 2026 年批次（研招网硕士专业目录）

`V6`、`V7` 两个迁移把研招网 2026 年硕士专业目录导入 `programs`：624 条记录、85 所院校、120 个专业，覆盖 T0/T1 为主的报考热门专业。每条记录带齐招生计划（含推免拆分）、考试科目、院系、研究方向、院校属性与来源。完整口径、字段字典和已知限制见 [院校专业数据抓取与说明.md](院校专业数据抓取与说明.md)，可视化版本见 `data/考研院校专业数据_2026.xlsx`。

## 既有快照（V5）

| JSON 字段 | 含义 |
| --- | --- |
| `id` / `snapshotId` | 专业记录标识、来源快照标识 |
| `schoolName` / `programName` | 学校名称、招生专业展示名；本批展示名含专业代码和院系 |
| `major` / `region` / `year` | 专业名称（关键字匹配）、地区（按数据库名称精确匹配）、招生年份 |
| `scoreLine` | 当年该条记录的复试总分线；未收录时为 `null` |
| `enrollment` | 本批上交大记录为校本部全日制统考计划人数；未收录时为 `null` |
| `admissionRatio` | 报录比；本批无可核实数据，统一为 `null` |
| `difficulty` | 既有接口的系统分组字段。本批没有难度评级，使用接口要求的常规分组，页面显示「未评级」 |
| `sources` | 来源标题、网址、发布单位、发布时间（未知则留空）、核验时间、来源版本 |

高校官网快照已导入本机 MySQL `kaoyan_ai`，共 23 条。新环境由 Flyway 自动应用 `V5__official_school_programs.sql` 和 `V9__school_retest_history.sql`。迁移使用固定 UUID，重复执行会跳过已存在的记录。
