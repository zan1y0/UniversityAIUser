## 4. 结构层模型训练（W2，约 11h）

### 4.1 统一训练循环（`src/kt/train.py`）
- 输入：嵌入拼接（题目/知识点/结果嵌入 + 特征路）→ 编码器 → Dropout(0.3) → 全连接 + sigmoid；
- 损失：`BCEWithLogitsLoss`；类别不均衡加正样本权重；
- 优化：Adam，weight_decay=1e-5；早停监控验证 AUC，连续 10 轮不提升回滚最优权重；
- batch 256；显存不足减小 batch + 梯度累积 2–4 步；
- 5 个随机种子取均值 ± 标准差；记录超参与划分；
- **5 折交叉验证**（按学生折分）：轨 A/B 各跑 5 折，记录折间均值±方差；
- **超参网格记录**：隐藏维 {64,128}、dropout {0.2,0.3}、学习率 {1e-3,5e-4}、序列长度 {50,100}。

### 4.2 M1 DKT（`src/kt/models/dkt.py`）
- 单层 LSTM(128)；输入嵌入 → LSTM → 预测头；
- 先在轨 A 复现论文量级指标，验证实现正确。

### 4.3 M3 AKT（`src/kt/models/akt.py`）
- Rasch 嵌入 + 上下文注意力；注意力头数按方案配置；
- 与 DKT 同输入同输出对比。

### 4.4 M4 GKT（`src/kt/models/gkt.py` + `src/kt/graph.py`，主线）
1. 建图：轨 B 用 `prerequisite.json`；轨 C 用项目知识树父子层级；轨 A 无先修图，按全连接邻接处理；
2. 归一化邻接：`Â = D^(-1/2)(A+I)D^(-1/2)`；
3. 一层 GCN：`H = ReLU(Â·E·W)`，`E` 为知识点嵌入；
4. 每步输入 `[H[skill_t], response_emb_t, ID-Free 特征_t]` → GRU(128) → 预测头；
5. BCE 训练；轨 B 预期 GKT ≥ DKT（+1~2 AUC 点为目标）；轨 A 持平属预期，写成"图结构收益依赖先修关系质量"。

## 6. 可信层（W3，约 3h）

### 6.1 MC-Dropout（`src/kt/calibrate.py`）
- 推理保持 dropout 开启，前向 N=10 次；批内并行 10 个不同 mask，避免延迟放大 10 倍；
- 输出 `p_mean`、`p_std`。

### 6.2 ECE 校准
- 10 分箱：`ECE = Σ(n_b/N)·|acc_b - conf_b|`，目标 <0.05；
- 出可靠性图（reliability diagram）；必要时做温度标定。

### 6.3 收缩融合
```
w      = min(n/10, 1) · max(0, 1 - p_std/σ0)   # σ0=0.25
mastery = w · p_mean + (1 - w) · rule_rate
```
- 样本多且自信 → 信模型；样本少/抖动大 → 退回规则；无记录返回 `null`；
- 画 `w` 关于样本数 n 的曲线，说明从规则到模型的平滑过渡。

### 6.4 选择性预测评估
- 覆盖率 50%/80%/100% 对应精度；说明"低置信度不输出"的代价。

### 6.5 检查点
- [ ] ECE <0.05，可靠性图落盘
- [ ] 收缩权重与 source（model/blend/rule）记录到样本输出
- [ ] 冷启动样本确实回退规则，不输出可疑 0/1

## 7. 决策层推荐（W3，约 3h）

### 7.1 贪心基线（`src/kt/recommend.py`）
- 按掌握度最低排序 Top-10；出 HR@10 / NDCG@10 / Recall@10。

### 7.2 LinUCB（`src/kt/bandit.py`）
- 臂 = 知识点；上下文 6 维：`[掌握度, 样本数(log), 最近正确率, 全局正确率, 距上次天数(log), 难度偏好]`；
- 打分：`score_a = θ_aᵀx + α·sqrt(xᵀ A_a⁻¹x)`；`A_a = Σxxᵀ + I`，`b_a = Σrx`，`θ_a = A_a⁻¹b_a`；
- `α ∈ {0.1, 0.3, 1.0}` 做敏感性分析；冷启动臂 `A_a=I` 天然高不确定性，自动探索。

### 7.3 离线策略评估 OPE（`src/kt/ope.py`）
- 用轨 C 模拟日志，记录策略 = 贪心，记录 `(context, action, propensity, reward)`；
- 本次只做 IPS 单估计器（SNIPS/DR 为裁剪项）；输出 IPS 估计值 ± 自助法 95% 置信区间，附策略 overlap；
- 口径：模拟器上的方法可行性验证，不是线上收益证明，结果记录与 `model/info` 明确标注。

### 7.4 掌握度聚合
- 知识点 k 下各题预测按时间衰减加权：`mastery_k = Σw_i p_i / Σw_i`，`w_i = exp(-Δt_i/14天)`，再套收缩融合。

### 7.5 检查点
- [ ] LinUCB vs 贪心在模拟器上的 HR/NDCG/Recall 与 IPS 对比表
- [ ] 探索率 α 敏感性结果落盘
- [ ] 推荐理由可解释（掌握度低 / 近 14 天未练 / 探索价值高）
