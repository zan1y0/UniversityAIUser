## 0. 立题：从"复现三个模型"到"解决一个真问题"

**一句话**：在公开数据上训练、在无标注的自有题库上可用，并把预测变成可解释、可评估的推荐决策。

对应四层，每一层都落到系统里的一个真实模块：

| 层 | 回答的问题 | 方法 | 对应功能 | 增量 |
| --- | --- | --- | --- | --- |
| **结构层** | "为什么这个模型更好？" | DKT → SAKT → AKT → **GKT（图知识追踪）** | 掌握度预测 | 必需 |
| **迁移层** | "公开数据的模型凭什么能服务我的题库？" | ID-Free 特征路 + **DANN 域对抗** | 跨域推理 | 可降级 |
| **决策层** | "预测出来了，然后推荐什么？" | **LinUCB 上下文赌博机** + IPS/DR 离线策略评估 | 推荐接口 | 必需 |
| **可信层** | "这个数字敢不敢用？" | MC-Dropout 置信区间 + ECE 校准 + 收缩融合 | 掌握度返回 | 必需 |

相对第一版方案（纯三代对照）的改动：

| # | 第一版 | 路线 B | 为什么改 |
| --- | --- | --- | --- |
| 1 | DKT/SAKT/AKT 三模型对照 | 增加 **M4 GKT**，用上项目自有知识树与 Junyi 先修图 | 三模型只是"复现对了"，GKT 才把项目资产变成算法输入 |
| 2 | ID-Free 靠随机丢 ID 路 | 升级为 **特征路 + DANN 梯度反转** | 从"技巧"变成"有理论依据的域自适应" |
| 3 | 推荐 = 加权排序 Top-10 | **LinUCB 决策 + 离线策略评估** | 从"排个序"变成"有策略、能证明比旧策略好" |
| 4 | 掌握度只给点估计 | **置信区间 + 校准 + 低置信度收缩到规则值** | 回答"模型什么时候不可信"，且不破坏契约四字段限制 |

## 1. 数据边界与待补字段（决定设计的边界）

### 1.1 当前代码现状（已核验；离线训练不依赖这些现状回接）

1. **`attempts` 暂无作答时长**：payload 为 `{id, sessionId, questionVersionId, answer, correct, score, maxScore, correctAnswer, explanation, wrongItemId, createdAt}`（`src/main/java/com/kaoyan/ai/service/PracticeService.java:157-181`），只有 `createdAt` 可作时间信号。
2. **模考暂不进序列**：模考答案存在 `exam_sessions.answers`，仅 `{questionId, answer, version, savedAt}`，连 `correct` 都没有（`src/main/java/com/kaoyan/ai/service/ExamService.java:94-108`）；逐题对错/得分落在 `exam_results.dimensions`，且 `dimensions` 未回写 `questionId`。→ 未补齐前训练/推理序列只覆盖练习流。
3. **旧契约几乎不给扩展空间**：`KnowledgeProgress.items` 为 `additionalProperties: false`，只能返回 `{knowledgeId, attemptCount, correctCount, mastery}` 四个字段；`algorithmVersion` 是 1–64 字符自由字符串（无枚举），可安全替换为模型版本号（如 `kt-gkt-v1`）。**→ 置信度不能塞进 op049/op073，必须走新增接口。**

### 1.2 后端待补字段（不阻塞训练；补齐后按"启用清单"接入）

> 口径：**特征管线按完整字段设计、各路特征全量保留，不因后端当前缺字段而砍特征路。** 训练输入以离线公开数据（轨 A/B）+ 本地模拟数据（轨 C）为准，后端库数据回接不前置。下表只说明"后端字段补齐后，训练侧能额外启用什么"；未补齐时对应特征在离线数据里用公开/模拟字段替代，模型结构与特征维度照完整方案搭建。

| 编号 | 数据源 | 待补字段 | 用途 | 离线训练时的替代口径 |
| --- | --- | --- | --- | --- |
| F1 | `attempts` | `durationMs`（作答时长）、`changed`（是否改答）、`attemptNo`（题内尝试次数） | 时长/犹豫类特征 | 特征路保留时长/改答/尝试次维度；公开数据缺该项时用模拟数据或零填充占位，维度不裁 |
| F2 | `attempts` | 冗余 `knowledgeId`、`subjectId` 快照；`seq`（会话内递增序号） | 免 join 映射知识点、稳定序列顺序 | 离线数据自带学生/题目/知识点 id 与顺序；回接后端时再反查目录补齐快照 |
| F3 | `exam_sessions.answers` | 回写 `correct`(0/1)、`score`、`knowledgeId`；`dimensions` 补 `questionId`；`status`（answered/skipped/unanswered） | 模考逐题可入训、漏答显式可分 | 模考标签待后端补齐后纳入；训练主序列先用练习流 + 公开/模拟数据，结构预留模考数据源 |

| F5 | 新增推荐/置信度接口 | `confidence`、`stddev`、`weight`、`source`、`modelVersion`、`reason` | 可信层结果落地、可解释依据 | 置信度/方差/权重在训练与服务内部照算；外显字段等后端新接口建好后对接，不影响训练计算 |
| F6 | 知识图谱 | 知识点先修关系边（`prerequisiteId`/边表） | GKT 先修图、先修未掌握推荐 | 轨 B 用 `prerequisite.json` 先修图、轨 C 用知识树父子层级；自有题库补边后 GKT 直接接入 |
| F7 | 题目元数据 | 结构化难度枚举或 0–1 难度分 | IRT 难度项、上下文特征 | 离线数据难度字段保留；公开/模拟侧按难度分布生成，维度不裁 |
| F10–F13 | 推理对接 | `MasteryPredictor` 接口+HTTP 客户端、`ai.kt.*` 配置与开关、60s 缓存与降级链、模型版本登记 | 自训模型回接后端、可回滚 | 属上线回接层，不影响离线训练；FastAPI 服务先独立跑通，Java 适配层后接 |
| F14–F18 | 治理/观测/测试 | 数据质量校验、`latencyMs/source/fallbackReason` 埋点、契约回归测试、导出脱敏与归属隔离、时区口径 | 样本干净、延迟可验收、对接不破坏旧契约 | 训练侧在离线管线自行过滤脏数据；观测/治理项随上线回接补齐 |

> 接入原则：特征管线与契约 DTO 按"字段可选、缺失归空"设计；**模型结构按完整字段搭建，特征路不预先砍掉**，后端补一个字段只把对应占位位接通，不返工主结构。完整待补清单（F1–F18，含类型建议、替代口径、优先级）见 `docs/后端数据字段待完善清单.md`。

另：仓库无任何真实用户作答数据，local 启动只生成"联调样例"种子；`docs/项目内容报告.md:14,377` 明确要求**不得声称"自带 AI 模型"**。本方案据此把交付定性为**离线自训 + 在线推理服务 + 可对接回接**。

## 2. 模型设计（四层）

### 2.1 结构层：四个模型 + 两个基线

| 代号 | 模型 | 出处 | 关键结构 | 参数量 | 作用 |
| --- | --- | --- | --- | --- | --- |
| B0 | 规则基线 | 对齐后端 `empirical-correct-rate-v1` | 历史正确率 | 0 | 降级兜底 + 下界 |
| B1 | IRT / 逻辑回归 | 经典测量理论 | 学生能力 θ − 题目难度 b | ~千 | 证明"神经网络确实学到了东西" |
| M1 | **DKT** | Piech et al., NeurIPS 2015 | 单层 LSTM(128) | ~0.3M | 第一代：循环 |
| M2 | **SAKT** | Pandey & Karypis, 2019 | 自注意力 1 层 4 头 | ~0.5M | 第二代：注意力 |
| M3 | **AKT** | Ghosh et al., 2020 | Rasch 嵌入 + 上下文注意力 | ~0.6M | 第三代：上下文感知 |
| **M4** | **GKT** | Nakagawa et al., 2019 | **知识点先修图 + GCN 聚合 + GRU** | ~0.4M | 本文主线：利用结构 |

**GKT 细节（这是路线的核心增量）**

1. 建图：轨 B 用 `prerequisite.json`（Junyi 先修关系），轨 C 用项目 `knowledge_trees.nodes` 的父子层级；轨 A（ASSIST09）本身无先修图，该轨按全连接邻接处理，**图结构收益依赖先修关系质量这一结论如实记录在实验结果中**，不影响 GKT 结构在 B/C 轨的完整实现。
2. 归一化邻接矩阵 `Â = D^(-1/2) (A + I) D^(-1/2)`，一层 GCN：`H = ReLU(Â · E · W)`，`E` 为知识点嵌入。
3. 每步输入 = `[H[skill_t], response_emb_t, ID-Free 特征_t]` → GRU(128) → 预测头。
4. 训练目标：BCE（下一题答对）。

**预期的诚实结论（先写在方案里，避免事后硬凑）**：ASSIST09 上 GKT 与 DKT/AKT 大致持平；Junyi 因为先修关系真实存在，GKT 应有可测提升（目标 +1~2 个 AUC 点）。若没提升，就作为"图结构收益依赖先修关系质量"的负结果写，仍然成立。

### 2.2 迁移层：ID-Free 特征路 + DANN 域对抗

**问题**：ASSISTments 上训练出的 `item_embedding[uuid]`，对本项目 `questionVersionId` 毫无意义，直接部署等于随机初始化。

**做法**：每步输入并行两路，模型内部拼接：

- **ID 路**（仅研究用）：`Emb(question_id) + Emb(skill_id) + Emb(response)`
- **特征路**（可跨域，8 维）：`[该知识点已作答次数, 该知识点历史正确率, 最近 3 次同知识点正确率, 距上次作答该知识点天数(log), 同题重试次数, 全局正确率, 题目难度, 序列位置]` → MLP(32)

**两级保障**：

| 级别 | 手段 | 训练 | 部署 |
| --- | --- | --- | --- |
| 基础（M5-a） | ID 路随机丢弃 `p=0.3` | 开 | 关（只走特征路） |
| 增强（M5-b） | **DANN**：在特征路隐层接域分类器（域 = 轨 A/B/C），梯度反转层 `GRL(λ)`，`λ = 2/(1+e^(-10p))-1` 随训练从 0 升到 1 | 开 | 关（推理不需要域分类器） |

DANN 的作用：让特征路的分布在三轨之间对齐，而不是只靠"丢 ID"碰运气。

**降级开关**：若 DANN 训练不稳定（表现为验证 AUC 抖动 > 0.02 或域准确率不降），回退到 M5-a，结果记录为"域对抗在小特征空间上收益不稳定"，仍是有效结论。

**素材价值**：给出三条曲线——全 ID 路 / 丢 ID 路 / DANN 对齐后的跨域 AUC。这就是"为什么能跨域"的证据链。

### 2.3 可信层：不确定性 + 校准 + 收缩融合

1. **MC-Dropout**：推理时保持 dropout 开启，前向 N=10 次 → `p_mean`、`p_std`。延迟增加约 10 倍，靠批量与缓存吸收（见 §5.3）。
2. **ECE 校准**：10 分箱，`ECE = Σ (n_b/N)·|acc_b - conf_b|`；出可靠性图（reliability diagram）。
3. **收缩融合（关键设计）**：旧掌握度接口只允许四个字段、暂无法塞置信度，所以**在数值层面处理不确定性**；置信度/标准差经新增接口（F5）单独返回：

```
w      = min(n/10, 1) · max(0, 1 - p_std/σ0)      # n=样本数, σ0=0.25
mastery = w · p_mean + (1 - w) · rule_rate        # rule_rate = 正确数/总数
```

- `w → 1`：样本多且模型自信 → 几乎全信模型
- `w → 0`：样本少或模型抖动 → 自动退回规则值
- 无任何作答记录 → 仍返回 `null`（不违反契约的 null 语义）

**这个设计的好处**：不改契约、不返回可疑的 0/1、冷启动天然安全；并可输出一条 "w 关于样本数" 的曲线，说明系统如何从规则平滑过渡到模型。

### 2.4 决策层：LinUCB 推荐 + 离线策略评估

**为什么不用贪心排序**：贪心只看"当前掌握度最低"，永远推同一个点，学生练完就没有探索，也无法证明"这个策略比旧策略好"。

**建模**：

- **臂（arm）= 知识点**（决策是"练哪个知识点"，具体题目再按难度匹配挑）→ 臂数量 = 科目知识点数，可控。
- **上下文（context, d=6）**：`[该点掌握度, 该点样本数(log), 该点最近正确率, 全局正确率, 距上次练该点天数(log), 题目难度偏好]`
- **UCB 打分**：`score_a = θ_aᵀx + α·sqrt(xᵀ A_a⁻¹ x)`，`A_a = Σ x xᵀ + I`，`b_a = Σ r x`，`θ_a = A_a⁻¹ b_a`
- `α` 控制探索强度，做 `α ∈ {0.1, 0.3, 1.0}` 敏感性分析
- 冷启动臂（`A_a = I`）天然给新知识点高不确定性 → 自动探索，无需手工加"novelty"项

**离线策略评估（OPE）**——因为系统还没有真实用户，这一步**必须在模拟器上做，并明确标注**：

1. 用 `kaoyan-sim` 生成 N=2000 个模拟学生 × 200 步的作答日志；
2. 用**记录策略**（logging policy）= 贪心排序产生日志，记录 `(context, action, propensity, reward)`；
3. 用 **IPS / SNIPS / DR** 三个估计器比较：贪心策略 vs LinUCB 策略；
4. 记录 `IPS 估计值 ± 自助法置信区间`，并附"记录策略与目标策略重叠度"（overlap）作为有效性证据。

> 口径边界："OPE 是在模拟器上做的，没有真实日志，因此它是**方法可行性验证**，不是线上收益证明。"该结论写进模型元数据与结果素材。

### 2.5 掌握度聚合

对知识点 k，用该点下所有题在当前序列末尾的预测正确率，按时间衰减加权：

```
mastery_k = Σ w_i · p_i / Σ w_i ,   w_i = exp(-Δt_i / 14天)
```

再套 §2.3 的收缩融合；`sampleCount` = 该点作答次数；无记录 → `null`。

## 6. Java 对接设计

### 6.1 结构（接口 + 三实现 + 降级链）

```java
public interface MasteryPredictor {
  Optional<ModelMastery> predict(String userId, String subjectId,
                                 List<AttemptPoint> history, List<Candidate> candidates);
}
```

- `HttpMasteryPredictor`：Spring `RestClient`，超时 800ms，失败/超时返回 `Optional.empty()`（中文注释说明"网络异常不外抛"）
- `RuleMasteryPredictor`：现有 `正确数/总数` 逻辑（原样保留，作为最终兜底）
- `FallbackMasteryPredictor`：按 `mode` 优先 model → bandit → greedy；全部失败才落到规则
- `algorithmVersion` 随实际路径写：`kt-gkt-v1` / `kt-bandit-v1` / `empirical-correct-rate-v1`

**失败不抛 5xx**：Dashboard / 薄弱点雷达是高频页面，模型服务挂掉时用户应当无感降级。

1. **交叉验证**：按学生做 **5 折交叉验证**（轨 A/B），记录均值 ± 标准差；§7.1 的 5 个随机种子保留，另补一折交叉验证表（小数据量下 5 折足够，不做复杂嵌套 CV）。
2. **超参调优记录**：固定网格内记录对比——隐藏维 {64,128}、dropout {0.2,0.3}、学习率 {1e-3,5e-4}、序列长度 {50,100}；给出最终选择与理由，体现"优化过程"而非单次跑通。
3. **效率对比表**：每模型列参数量、单批推理耗时、p95 延迟；说明 GKT/AKT 精度与效率的取舍。
4. **数据合规说明**：轨 A/B 为公开学术数据集（注明来源与用途）；轨 C 为模拟生成、不含真实学生隐私；自有题库仅取题目结构与作答统计，不导出答案解析等敏感内容。该说明写入模型元数据与素材，供文档引用。
