### 4.1 统一训练循环（`train.py`）✅ 已实现
- 输入：嵌入拼接（题目/知识点/结果嵌入 + 特征路）→ 编码器 → Dropout(0.3) → 全连接 + sigmoid。
- 损失：`BCEWithLogitsLoss`（`reduction="none"` 后乘 mask，只算有效步）。
- 优化：Adam，weight_decay=1e-5；梯度裁剪 1.0；早停监控验证 AUC，连续 10 轮不提升回滚最优权重。
- batch 256；右 padding + mask，单向 LSTM 故无需 `pack_padded_sequence`。
- 5 个随机种子取均值 ± 标准差；记录超参与划分。
- 实现文件：`src/kt/train.py`（`build_all` / `run_track`），入口 `scripts/train_model.py`（旧入口 `train_dkt.py` 保留）。

### 4.2 M1 DKT（深度知识追踪，`dkt.py`）✅ 已实现并实测达标
- 结构：知识点嵌入(64) ‖ 上一步作答嵌入(64) ‖ 8维特征 MLP(32) → LSTM(128) → Dropout(0.3) → 线性头。
- 防泄漏：作答输入右移一位（位置 t 只看到 t−1 的答案），`resp_in=-1` 表示无上一步。
- 实测（5 种子 42–46，batch 256，30 轮，早停 patience=10）：

| 轨 | test AUC | 标准差 | ACC | F1 | LogLoss | 最优种子 |
| --- | --- | --- | --- | --- | --- | --- |
| A | **0.7990** | 0.0005 | 0.7482 | 0.8170 | 0.5105 | 42（验证 0.8004） |
| B | **0.9105** | 0.0001 | 0.8379 | 0.8439 | 0.3787 | 45（验证 0.9126） |

- 对照组（同划分同指标）：轨 A B0 0.6827 / B1 0.7689 / **DKT 0.7990**；轨 B B0 0.8474 / B1 0.8765 / **DKT 0.9105**。
- 相对规则基线增益：轨 A +0.1163、轨 B +0.0631，均超过 +0.06 验收线。
- 分档 AUC（seed 42）：轨 A `n<5` 0.7878 / `5≤n<20` 0.8050 / `n≥20` 0.8019；轨 B 0.9041 / 0.9166 / 0.9032——**冷启动档低于熟练档**，符合知识追踪"样本越多预测越准"的预期。
- 工程事实：`std_auc` 极小（0.0001–0.0005）是因为轨 B 训练步数达 285 万，初始权重差异被大量梯度更新抹平；不是泄漏，已由序列自检与"相对规则增益"双重验证。

### 4.4 M4 GKT（图知识追踪，`gkt.py` + `graph.py`，主线）✅ 已实现并实测
1. 建图：轨 B 用 `prerequisite.json`（原始 985 条边，两端都在词表内 902 条；节点覆盖 705/719 = 98.1%，孤立节点 14 个，平均度 2.5）；轨 A 无图退化为全连接；`identity` 仅自环作消融。
2. 归一化邻接：`Â = D^(-1/2)(A+I)D^(-1/2)`。
3. 一层 GCN：`H = ReLU(Â·E·W) + E`——**必须加残差**，否则 Â 把自环权重压到约 1/(deg+1)，自身信息被稀释。
4. 每步输入 `[H[skill_t], response_emb_t, ID-Free 特征_t]` → GRU(128) → 预测头。
5. 实测 5 种子：轨 A **0.7982 ± 0.0005**、轨 B **0.9105 ± 0.0001**。

**结论（如实记录）**：轨 B 上 GKT 与 DKT **完全持平**（0.9105 vs 0.9105，差 0），图结构未带来精度增益。原因三条：
- 平均度仅 2.5，单层 GCN 聚合的邻居信息量很小；
- 序列模型已从「该知识点自身作答历史」学到掌握度，先修邻居的边际信息与之高度重叠；
- 数据集接近饱和：B0 规则已 0.8474，DKT 0.9105，剩余空间仅约 0.06。

→ **GKT 的定位改为「可解释性」而非「提分」**：能输出"因为先修 k_x 未达标，所以推荐 k_y"，这是纯序列模型给不出的推荐依据。

**轨 A 上 GKT 略低（0.7982 vs 0.7990，−0.0008）的机制**：无先修图时退化为 113×113 全连接，`Â` 把所有知识点嵌入互相平均，导致表示趋同、区分度下降。属预期行为，反证"图必须有真实先修关系才有意义"。

**图结构消融实验（ablation，切除对照）**：固定 GKT 的 GCN+GRU 结构不变，只把邻接矩阵换成单位阵（`--graph-mode identity`），使 GCN 失去邻居可聚合，从而单独分离"图聚合"与"编码器差异"两个变量。

| 配置 | 轨 B test AUC |
| --- | --- |
| `prereq`（先修图，902 条可用边） | 0.9105 ± 0.0001 |
| `identity`（单位阵，无邻居聚合） | 0.9105 ± 0.0001 |
| **差值（图聚合的真实贡献）** | **0.0000** |

**结论：图聚合的精度贡献精确为零。** 这不是"图没用"的模糊判断，而是逐位可查的实测：拆掉图，指标一位不变。由此排除"图有用但被 GRU（门控循环单元）劣势抵消"这一解释——两个变量已完全分离。

## 阶段 5：迁移层（W3，约 3h）

### 5.1 M5-a 丢 ID 消融

- 记录全 ID 路 / 丢 ID 路两条跨域 AUC 曲线。

### 5.2 M5-b DANN（`dann.py`，可降级）
- 特征路隐层接域分类器（域 = 轨 A/B/C）。

- 推理时关闭域分类器。
- 降级条件：验证 AUC 抖动 >0.02 或域准确率不降 → 回退 M5-a，作为负结果记入实验记录。

### 5.3 检查点

### 5.4 实测结果（2026-11-19）

**M5-a 丢 ID 消融**（轨 B，DKT，5 种子 42–46，20 轮）：

| 配置 | test AUC | 标准差 | 相对有 ID | 逐种子 |
| --- | --- | --- | --- | --- |
| 有 ID（正式结果） | 0.9105 | 0.0001 | — | 0.9105 / 0.9107 / 0.9105 / 0.9106 / 0.9104 |
| 训练丢 30%（p=0.3，评估全丢） | 0.9056 | 0.0001 | −0.0049 | 0.9055 / 0.9056 / 0.9058 / 0.9057 / 0.9056 |
| **全程无 ID（p=1.0）** | **0.9063** | **0.0000** | **−0.0042** | 0.9063 / 0.9062 / 0.9063 / 0.9063 / 0.9063 |

**结论：去掉全部知识点编号，AUC 只掉 0.0042（0.42 个百分点），远低于验收线 0.06。** 模型不依赖题库编号，换学校/换题库仍可用。

两个值得记录的细节：

1. **p=1.0 反而优于 p=0.3（0.9063 vs 0.9056）**。原因是训练-推理不一致：p=0.3 时 70% 的批次仍带编号，但评估时 100% 无编号，模型在两种输入分布间摇摆；p=1.0 训练与评估完全一致，模型更专一。**结论：要么全给、要么全不给，别做"半丢"**。
2. **p=1.0 的 5 个种子完全相同（std=0.0000）**。因为编号嵌入完全不参与梯度，参数里的随机性来源被消除。

**工程含义（部署选型）**：

| 权重 | AUC | 是否需要题库编号 | 换题库能否直接用 |
| --- | --- | --- | --- |
| `dkt_b.pt`（有 ID） | 0.9105 | 需要，且必须是训练时的编号体系 | ❌ 编号对不上就失效 |
| `dkt_b_noid100.pt`（无 ID） | 0.9063 | 不需要，只用 8 维特征 + 作答序列 | ✅ 可直接用于任何题库 |

**建议对外服务用 `dkt_b_noid100.pt`**：用 0.42 个点的代价换取完全的可迁移性，对"跨校推广"这一产品目标更划算。有 ID 的权重保留作为同题库场景的性能上限对照。

**M5-b DANN 跨域对照**（源域 A → 目标域 B，15 轮，两个数据量场景）：

| 场景 | source_only | mixed | mixed + DANN | DANN 相对 mixed |
| --- | --- | --- | --- | --- |
| 目标域全量（5.36 万序列） | 0.7562 | **0.9024** | 0.8939 | **−0.0085** |
| 目标域 20%（1.07 万序列） | 0.7562 | **0.8975** | 0.8789 | **−0.0186** |

**结论：两个场景下 DANN 均无正收益，判为无效模块，作为负结果记录。**

三条原因：

1. **目标域数据量足以覆盖分布**：目标域从全量降到 20%，mixed 只掉 0.0049（0.9024→0.8975）。因为轨 B 的 test 学生与 train 学生同分布，20% 样本已覆盖分布，域差异不需要靠域不变约束解决。
2. **域分类器类别不平衡**：源域 44,453 序列 vs 目标域 10,712 序列（约 4:1），域分类器倾向于猜"源域"，反向梯度质量差，反而干扰主干（20% 场景掉得更多 −0.0186 比全量 −0.0085 更差，正对应此点）。
3. **域信息里有一部分对预测有用**：英文数学题与中文数学题的作答节奏本就不同，GRL 强行抹平会丢失真实信号。

**这一组对照的真正价值**：

- `source_only` 的 **0.7562** 证明"拿 A 的模型直接用在 B"会掉 14.6 个点，跨域问题真实存在；
- `mixed` 的 **0.9024** 证明"两域数据一起训练"就能解决，成本远低于设计域对抗模块；
- 因此跨域问题的解法是**数据混合**，不是**域对抗**。这个负结果说明了模块选型有依据，不是盲目堆叠。

> **诚实标注**：本跨域实验的"目标域"仍是同数据集内的学生划分，不是真正的新学校/新题库。真正的迁移能力验证应看 `source_only → mixed` 这段 14.6 点的差距能否在其他数据集上复现。

## 阶段 6：可信层（W3，约 3h）

### 6.1 MC-Dropout（`calibrate.py`）
- 推理保持 dropout 开启，前向 N=10 次；批内并行 10 个不同 mask，避免延迟放大 10 倍。
- 输出 `p_mean`、`p_std`。

### 6.2 ECE 校准
- 10 分箱：`ECE = Σ(n_b/N)·|acc_b - conf_b|`，目标 <0.05。
- 出可靠性图（reliability diagram）；必要时做温度标定做校准。

### 6.3 收缩融合
```
w      = min(n/10, 1) · max(0, 1 - p_std/σ0)   # σ0=0.25
mastery = w · p_mean + (1 - w) · rule_rate
```
- 样本多且自信 → 信模型；样本少/抖动大 → 退回规则；无记录返回 `null`。
- 画 `w` 关于样本数 n 的曲线，说明从规则到模型的平滑过渡。

### 6.4 选择性预测评估
- 覆盖率 50%/80%/100% 对应精度；说明"低置信度不输出"的代价。

### 6.5 检查点
- [x] ECE <0.05，可靠性图落盘
- [x] 收缩权重与 source（model/blend/rule）记录到样本输出
- [x] 冷启动样本确实回退规则，不输出可疑 0/1

### 6.6 实测结果（2026-11-19，`dkt_b_noid100.pt`，轨 B 测试集 58.9 万步）

**MC-Dropout 与校准**（N=10 次采样）：

| 指标 | 数值 | 判定 |
| --- | --- | --- |
| test AUC | 0.906（标定前后一致） | ✅ 单调变换不改排序，自检通过 |
| ECE（校准前） | **0.0027** | ✅ 远优于 0.05 验收线 |
| ECE（温度标定后） | 0.0029 | 略升，说明 T≈1，**无需标定** |
| Brier | 0.121 → 0.121 | 良好（全猜 0.5 为 0.25） |
| p_std 均值 / P50 / P90 | 0.0269 / 0.0255 / 0.0417 | 不确定性信号存在但偏小 |

**结论：模型天然校准良好，温度标定判定为不必要（与 DANN 一样属于"验证后判定不必要"）。**

原因：训练目标 BCE 本身是 proper scoring rule（恰当评分规则），已经优化了概率校准；5.9 万测试样本让分箱统计非常稳定。因此 ECE 0.0027 不是巧合，是训练目标与数据量的必然结果。

**收缩融合**（σ0=0.25，n_full=10）：

| 指标 | 数值 |
| --- | --- |
| w 均值 | 0.6792 |
| 来源 model / blend / rule / null | 333,907（69.2%）/ 106,535（22.1%）/ 99,091（20.5%）/ **49,704（10.3%）** |
| 融合后 AUC | 0.9016（纯模型 0.906，−0.0044） |

三条判读：

1. **10.3% 样本返回 null**：这些是"第一次作答该知识点"（n=0），无历史可依，拒答是设计正确的行为——不会输出可疑的 0 或 1。这一条直接对应检查点"冷启动样本确实回退规则"。
2. **w 由样本数主导**：p_std 仅 0.027，`1−p_std/0.25 ≈ 0.89`，所以 w 实际近似 `min(n/10,1)`。若要让不确定性真正起作用，需提高采样数或加大 dropout。
3. **AUC −0.0044 是预期权衡**：20.5% 的样本退回规则（历史正确率），规则弱于模型，整体略降。这是"可信度换精度"，不是退步。

**选择性预测（低置信度拒答）**：

| 覆盖率 | ACC | 相对全量 |
| --- | --- | --- |
| 50%（只答最自信的一半） | **0.8951** | **+0.0601** |
| 80% | 0.8602 | +0.0252 |
| 100%（全答） | 0.8350 | — |

**覆盖率从 100% 收缩到 50%，精度提升 6 个百分点。** 说明 p_std 的排序有效，模型"知道自己不知道"。这是可信层最有说服力的结果。

**有 ID / 无 ID 两个权重的可信度对照**：

| 指标 | 有 ID（`dkt_b.pt`） | 无 ID（部署用 `dkt_b_noid100.pt`） | 差异 |
| --- | --- | --- | --- |
| test AUC | 0.9105 | 0.9061 | −0.0044 |
| ECE 校准前 → 后 | 0.0051 → 0.0052 | **0.0031 → 0.0030** | 无 ID 更低 |
| Brier | 0.1183 | 0.1210 | +0.0027 |
| p_std 均值 | 0.0257 | 0.0269 | +0.0012 |
| 融合 w 均值 | 0.6835 | 0.6792 | −0.0043 |
| 融合后 AUC | 0.9046 | 0.9017 | −0.0029 |
| 选择性 50% 覆盖 ACC | 0.8982 | 0.8957 | −0.0025 |

**关键结论：去掉知识点编号后，精度只掉 0.0044，但校准质量反而提升（ECE 0.0051 → 0.0031），不确定性略增（+0.0012）。**

机制：有 ID 的模型记住了编号，在见过的知识点上容易过度自信；无 ID 的模型只能依赖行为特征，预测分布更平滑、更少极端值，因此校准反而更好。这印证了"信息少 → 更不自信 → 置信度更准"这一直觉。

**因此部署用无 ID 权重，不只在可迁移性上更优，在可信度上也不输。**

## 阶段 7：决策层推荐（W3，约 3h）

### 7.1 贪心基线（`recommend.py`）
- 按掌握度最低排序 Top-10；出 HR@10 / NDCG@10 / Recall@10。

### 7.2 LinUCB（`bandit.py`）
- 臂 = 知识点；上下文 6 维：`[掌握度, 样本数(log), 最近正确率, 全局正确率, 距上次天数(log), 难度偏好]`。
- 打分：`score_a = θ_aᵀx + α·sqrt(xᵀ A_a⁻¹x)`；`A_a = Σxxᵀ + I`，`b_a = Σrx`，`θ_a = A_a⁻¹b_a`。
- `α ∈ {0.1, 0.3, 1.0}` 做敏感性分析；冷启动臂 `A_a=I` 天然高不确定性，自动探索。

### 7.3 离线策略评估 OPE（`ope.py`）
- 用轨 C 模拟日志，记录策略 = 贪心，记录 `(context, action, propensity, reward)`。
- **本次只做 IPS 单估计器**（SNIPS/DR 为裁剪项）；输出 IPS 估计值 ± 自助法 95% 置信区间，附策略 overlap。
- 口径：模拟器上的方法可行性验证，不是线上收益证明，结果记录与 `model/info` 明确标注。

### 7.4 掌握度聚合（`features.py`/聚合段）
- 知识点 k 下各题预测按时间衰减加权：`mastery_k = Σw_i p_i / Σw_i`，`w_i = exp(-Δt_i/14天)`，再套收缩融合。

### 7.5 检查点
- [x] LinUCB vs 贪心在模拟器上的 HR/NDCG/Recall 与 IPS 对比表
- [x] 探索率 α 敏感性结果落盘
- [x] 推荐理由可解释（掌握度低 / 近 14 天未练 / 探索价值高）

### 7.6 实测结果（2026-11-19，轨 B，2000 学生 × 20 轮，日志 4 万条）

**奖励定义**：本次作答带来的**掌握度增益**，不是答对与否。
期望增益 `g(m) = 0.06·m(1−m) − 0.03·m·(1−m) = 0.03·m·(1−m)`，顶点在 **m = 0.5**（最近发展区 ZPD）。

**策略对比（平均掌握度增益）**：

| 策略 | 平均增益 | 答对率 | 每步遗憾 | 覆盖臂 |
| --- | --- | --- | --- | --- |
| random | 0.00270 | 0.5284 | 0.00445 | — |
| greedy（硬选最低掌握度） | 0.00341 | 0.0591 | 0.00373 | — |
| greedy-softmax（记录策略，即日志本身） | 0.00488 | 0.2842 | — | — |
| LinUCB α=0.1 | 0.00483 | 0.4064 | 0.00231 | 74.1% |
| **LinUCB α=0.3（推荐）** | **0.00526** | 0.4101 | **0.00188** | 76.6% |
| LinUCB α=1.0 | 0.00507 | 0.4078 | 0.00207 | 89.4% |

**贪心离线排序指标**：

| 指标 | 数值 | 说明 |
| --- | --- | --- |
| HR@10 | **1.0** | 完美命中"最需要练的 top-50" |
| Recall@10 | 0.4607 | 学生可练知识点平均仅约 21 个，故上限接近 0.5 |
| NDCG@10 | **1.0** | 排序完全正确 |
| 平均期望增益 | 0.0031 | **远低于 LinUCB 的 0.00526** |
| 需要练习的知识点占比 | 96.66% | 未作答过的知识点按 0.5 计，低于阈值 0.6 |

**三条核心结论**：

1. **"补最短板"不是最优推荐。** 贪心 HR@10 与 NDCG@10 都是 1.0——严格按"最缺什么补什么"排序，但平均掌握度增益只有 0.00341，比 LinUCB 低 54%。原因：掌握度最低的约 0.06，答对率仅 5.9%，学生做了也学不进去。
2. **ZPD（最近发展区）才是最优区间。** 期望增益 `g(m)=0.03·m·(1−m)` 在 m≈0.5 达到最大。LinUCB 借由第 7 维"ZPD 契合度"特征 `1−|2m−1|` 学到这一点，转向中等难度知识点，增益提升到 0.00526。
3. **探索本身有价值。** 硬贪心 0.00341 → 软贪心（top-10 内随机，即记录策略）0.00488 → LinUCB 0.00526，逐级上升。软策略明显优于硬贪心，说明"只盯一个最短板反复练"会浪费机会。

**α 敏感性（倒 U 形，最优在 0.3）**：

| α | 平均增益 | 覆盖臂 | 判读 |
| --- | --- | --- | --- |
| 0.1 | 0.00483 | 74.1% | 探索不足，部分知识点从未被尝试 |
| **0.3** | **0.00526** | 76.6% | 平衡点 |
| 1.0 | 0.00507 | 89.4% | 探索过度，把机会花在已知差的臂上 |

**IPS（逆概率加权）离线评估**：

| 指标 | 数值 | 判定 |
| --- | --- | --- |
| IPS 估计 | 0.0051 | 与在线 LinUCB 的 0.00526 接近，方向一致 |
| 95% 置信区间 | [0.0030, 0.0070] | 宽度 0.004，相对宽度约 78% |
| ESS（有效样本量） | 321（10.7%） | ❌ 低于 20% 健康线 |
| 策略重叠度 | 0.1233 | ❌ 低于 0.5，新旧策略选的知识点差异很大 |
| SNIPS（自归一化） | 0.0052 | 与 IPS 一致，互为印证 |
| 权重裁剪率 | 0% | 无极端权重，clip 未触发 |

**诚实结论**：IPS 点估计与在线结果一致（差 0.0002），但 ESS 仅 10.7%、重叠度仅 0.123，说明**策略改动越大，IPS 越不可靠**——这是离线策略评估的已知局限（support issue），不是实现缺陷。因此 IPS 只作**方向性参考**，不作定量结论。

对照意义：日志策略自身增益 0.00488，IPS 估出的新策略 0.0051，说明"新策略不比旧策略差"这一判断可信；但"具体好多少"需线上 A/B 才能定量。

**推荐理由的可解释输出**（后端契约用）：

| 情形 | 推荐理由文案 |
| --- | --- |
| 掌握度 < 0.4 | "该知识点薄弱，建议优先巩固" |
| 0.4 ≤ 掌握度 < 0.7 且 ZPD 契合度高 | "难度与你当前水平匹配，学习效率最高" |

| 探索项主导（不确定性高） | "该知识点样本较少，系统正在补充数据" |

| 缩写 | 英文全称 | 中文 | 一句话解释 |
| --- | --- | --- | --- |
| AUC | Area Under the ROC Curve | ROC 曲线下面积 | 随机取「答对」与「答错」两个样本，模型给答对者打分更高的概率。0.5=瞎猜，1.0=完美 |

### A.5 数据处理与实验设计

| 缩写 | 英文全称 | 中文 | 一句话解释 |
| --- | --- | --- | --- |
| ID-Free | Identification-Free | 无 ID 依赖 | 不依赖题目/知识点编号的特征路，使模型可迁移到新题库 |
| LOO | Leave-One-Out | 留一法 | 计算统计量时剔除当前样本自身，防止标签泄漏 |
| 轨 A/B/C | Track A/B/C | 数据轨道 | A=ASSIST09（英文数学，论文对标）、B=Junyi（中文数学，含先修图）、C=项目模拟数据 |
| 消融 | Ablation | 消融实验 | 只关掉一个组件、其余不变，测量该组件的净贡献 |
| OPE | Offline Policy Evaluation | 离线策略评估 | 不上线就估计推荐策略的收益 |

| MC-Dropout | Monte Carlo Dropout | 蒙特卡洛 Dropout | 推理时也开 Dropout 采样多次，用结果方差估计不确定性 |
