# 后端数据字段待完善清单（供后端排期）

> 原则：字段一律**可选、缺失归空**；**特征管线按完整字段设计、各路特征全量保留，不因后端当前缺字段而砍特征维度**。训练不以后端补齐为前置条件，先用离线公开 + 模拟数据跑通；下表"离线替代口径"列说明未补齐时训练侧如何占位/替代，后端补一个字段只接通对应占位位，不返工主结构。

## 五、接入约定

1. 新字段在请求/响应 DTO 中**可空**，老调用方不传不报错。
2. 训练特征管线按"字段存在则启用、缺失归默认占位值"设计，**特征维度按完整方案固定，不随后端缺字段删减**，避免后端补字段时改训练主结构。

4. 字段补齐后请在本清单对应行标注落地版本/日期，训练侧据此把对应占位位切到真实字段。
