## 三、为什么这三块这次没拿到（都是源站限制，不是没找）

1. **2024 校线**：研招网 34 所页面（如北大 2024）正文是 **PNG 图片**，没有表格、没有 PDF。要取数只能 OCR，本机没有 OCR 运行环境，硬写就是猜数。
2. **2025 校线**：页面给了 PDF，但每所学校的 PDF 表头/列序都不同（有的列“政治/外语/专业课1/专业课2/总分”，有的少一列），逐校适配才能保证不错行；本次试解析北大只稳定得到 1 行，因此**宁可留空也不填错**。
3. **2023–2025 各专业招生计划**：研招网「硕士专业目录」只保留**当年**目录，站点现已切到 2027 年目录，2023–2025 的目录页已经下线；Wayback 对 `zsml` 的存档只有个位数快照，无法还原。唯一可靠来源是**每所学校研究生院官网当年的招生专业目录**（HTML 表格 / PDF / Excel 附件），必须逐校抓取并逐校适配版式。
4. **报录比**：只有少数院校（如深圳大学、上海大学等）在官网公示“报考人数/录取人数”，其余不公开；教育在线等聚合站的 2023 年以后数据也很稀疏。

## 四、要把「全部院校 × 全部专业 × 2023–2025」补齐，必须这么做

按学校逐批抓官网，每所学校 1–3 个页面/附件：

1. 定位研究生院站点 → 「招生工作 / 硕士招生」栏目；
2. 找当年《硕士研究生招生专业目录》和《复试分数线》公告；
3. 解析 HTML 表格，或下载 PDF/Excel 附件后解析；
4. 归一化成同一套字段，附原文链接与抓取时间；
5. 每批 50 所，产出同结构 CSV/Excel，可断点续跑。

预计：普通本科院校版式更简单，单校 2–4 个请求；850 所 × 3 年约 5,000–8,000 个请求，按站点限速（约 1–2 请求/秒）需要 **6–10 小时**，分 4–6 批完成。
