# 数字人陪伴督学

学生登录后，点击悬浮机器人「研小途」→ 拍照旁的「设置」。在「模式切换」中选择学霸、温柔或严管模式；顶部徽标显示当前模式。模式沿用现有数字人用户设置，和旧的数字人设置接口共用数据。没有保存过模式的账号默认使用温柔模式。

## 答辩与正式流程

1. 点击「预览督学反馈」。依次切换三个模式，用相同的英语长难句任务比较徽标、提醒、主操作、动作与完成反馈。可以朗读同一份文案。预览操作不调用正式任务接口。未配置后端时，可在登录页点「先逛逛学习空间」走预览流程。
2. 测试正式流程时，先在「学习计划」生成并确认一份计划。返回机器人 → 设置 → 管理任务时间，选择任务日期，再点「设置开始时间」。输入和展示均为北京时间。
3. 选择严管模式可最快观察实际提醒：保存当前分钟的开始时间，等下一次后台扫描。点击「调整时间」可保存新的计划时间，点击「立即开始计时」会启动卡片对应的任务。温柔模式的卡片会启动 5 分钟计时；到时可以继续、结束本次专注，或明确标记任务完成。刷新与切换模式均会保留计时。
4. 明确标记任务完成后，在机器人中查看对应的完成反馈。实际专注时段进入现有学习统计；开始或结束专注不会自动打卡。学霸模式只在任务有真实优先级和预计用时时比较优先级，默认生成的学习计划没有优先级，所以会推荐当前任务。

## 迁移与接口

- 使用项目现有启动方式：本地 H2 执行 `./scripts/start-local.ps1`，已配置的 MySQL 执行 `./scripts/start-mysql.ps1`；另开终端在 `frontend` 执行 `npm run dev`。
- Flyway 按当前环境自动运行 `V4__study_supervision.sql`。新表保存计划开始时间、任务专注和提醒回执；旧计划不补造开始时间。模式保存在现有 `avatar_preferences`。部署 MySQL 时，确保现有 Flyway 迁移账号有建表和索引权限。启动日志应显示版本 `v4`。
- 接口遵循仓库 OpenAPI、登录和 CSRF 约定：`GET/PUT /api/v1/study-mode`、`GET /api/v1/study-supervision?date=YYYY-MM-DD`、`PUT /api/v1/study-supervision/tasks/{taskId}`。旧提醒设置仍可读取和保存；任务提醒改按每项任务的计划开始时间触发，旧每日时间不再触发任务提醒。
- 后端每分钟扫描一次，前端每 15 秒刷新提醒卡片和机器人提示徽标。首次提醒在三模式间共用；严管追加只在首次早于第 5 分钟且任务仍未开始时发出。提醒状态按用户、任务、计划时间和轮次保存，刷新或再次保存相同时间不会重发。

## 验证命令

- 仓库根目录：`mvn test`、`mvn package`、`python scripts/sync-contract.py --check`。
- 前端目录：`npm run build`、`npm test`、`npm run test:e2e`。
- 真实 MySQL 专项：将 `STUDY_TEST_MYSQL_URL` 指向独立测试库，使用已有 MySQL 用户配置，然后运行 `mvn "-Dstudy.mysql.test=true" "-Dtest=StudySupervisionMysqlTests" test`。测试库应允许 Flyway 迁移，测试业务数据在每例结束后回滚。
