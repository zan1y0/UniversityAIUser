# 包目录与调用顺序

更新日期：2026-11-08。Java 包按功能归组，根包从 12 个收敛为 5 个。IDE 按名称排列，同一功能下的包通过父包集中展示。

```text
com.kaoyan.ai
├─ api                           请求入口
│  ├─ controller                 接口与路由
│  ├─ security                   SessionFilter：身份、来源与 CSRF 检查
│  ├─ contract                   契约校验、事务和幂等入口
│  └─ advice                     全局 HTTP 异常处理
├─ service                       业务处理
│  ├─ 各模块 Service             学习计划、答疑、练习、模考、资讯等
│  ├─ auth                       账户认证、JWT、会话服务
│  └─ task                       异步任务、提醒、事件和定时处理
├─ persistence                   数据访问
│  ├─ repository                 聚合、归属、版本和 JSON 适配
│  ├─ mapper                     MyBatis Mapper 接口
│  └─ entity                     数据库映射实体、表名白名单
├─ infrastructure                基础设施
│  ├─ ai                         外部模型服务适配
│  ├─ storage                    私有文件和音频检查
│  ├─ cache                      Redis 缓存与启动连通性检查
│  └─ config                     本地初始化配置
├─ common                        公共工具、业务异常
└─ KaoyanAiApplication           Spring Boot 启动入口
```

上图按阅读和调用顺序展示；IDE 内各组仍按字母排序，无需给 Java 包添加数字前缀。

## 顺着一次请求阅读代码

1. `api.security.SessionFilter`：检查身份和 CSRF。
2. `api.controller`：接收 HTTP 请求。
3. `api.contract.ApiExecutor`：校验接口契约，开启事务，处理幂等。
4. `service.DomainDispatcher` 和各模块 Service：处理业务规则。
5. `persistence.repository`：处理聚合、归属与版本。
6. `persistence.mapper`：执行 `resources/mapper/*.xml` 中的 SQL。
7. MySQL：返回数据，再逐层构造响应。

注册登录走 `AuthController → service.auth.AuthService → Repository/Mapper`；后台任务从 `service.task` 进入；模型与文件功能调用 `infrastructure.ai/storage`；Redis 缓存调用 `infrastructure.cache.RedisCache`；错误由 `api.advice.ApiAdvice` 统一处理。

## 包调整对照

| 原位置 | 当前位置 |
| --- | --- |
| `controller` | `api.controller` |
| `contract` | `api.contract` |
| `security.SessionFilter` | `api.security.SessionFilter` |
| `security` 中的 3 个 Service | `service.auth` |
| `jobs` | `service.task` |
| `repository` | `persistence.repository` |
| `mapper` | `persistence.mapper` |
| `entity` | `persistence.entity` |
| `ai`、`storage`、`config` | `infrastructure` 下的对应子包 |
| `common.ApiAdvice` | `api.advice.ApiAdvice` |

同步修改 Java 包声明与导入、测试引用、MyBatis 扫描路径、XML namespace/实体类型和契约同步脚本。SQL 映射文件仍放在 `src/main/resources/mapper/`，数据库连接配置、表结构和接口 URL 保持原样。

MySQL 启动与验证方法见 [MyBatis 与 MySQL 说明](MyBatis迁移与MySQL验证.md)。
