# UniversityAIUserPage

大学生考研AI导学系统的独立前端。Vue 3 + TypeScript strict + Vite + Pinia + Vue Router，包含原文11个模块。本次只实现、审查与运行前端，不处理Nginx部署或后端业务。

## 在 VS Code 本地运行

直接打开本文件所在的 `UniversityAIUserPage` 文件夹，在终端执行：

```powershell
npm ci
npm run dev
```

访问 http://127.0.0.1:5173/ 。本机依赖已安装。需要 Node.js >=22.12.0。VS Code“终端 → 运行任务”提供开发服务、类型检查和测试入口。

默认是**演示模式**：没有后端也能打开全部11个模块，使用明确标注的合成学习数据验证交互。演示回复、录取资料、评分和统计不是实际业务结果。

点击右上角切换到**真实接口模式**：账号登录、档案、学习资料和所有操作通过正式 `/api/v1` 契约。后端尚未实现或不可用时显示明确错误，绝不悄悄回退演示。网页不能代替真实AI、OCR、评分或数据库服务。

## 正式 API 与页面实现

- 唯一接口契约：`contracts/openapi.json` / `openapi.yaml`，对应Apifox“考研 AI 导学系统 · API 契约 v1.0.0”。本次没有更改这份契约。
- `src/api/generated.ts`：81个操作的TypeScript输入/输出类型及216个Schema类型。
- `src/api/schema.ts` / `contract-data.json`：字段、枚举、必填、边界、条件分支、空值和未知字段的运行时校验。
- `src/api/client.ts`：Session Cookie、登录前CSRF、统一错误码、traceId、204、FormData、私有下载、请求超时及取消。没有保留旧 `/api/user/login` 适配或数字200成功码兼容。
- `src/api/contract.ts`：严格操作入口、幂等键、异步任务查询与SSE事件。重试复用原请求体和幂等键，版本冲突不会自动覆盖记录。
- `src/components/ContractWorkspace.vue`：真实模式的11模块学习操作面板，复用契约表单、关联资料选择、内容与反馈展示。档案在学习计划中维护，附件在答疑、数字人与复试中管理；不新增业务模块。
- `src/views/`：11模块的本地演示页面与登录页，保留完整原有交互。

**字段和请求方式以契约为准，禁止任一端私自更名。** 章节编号、教材版本和考试类型等依赖实际课程资料与后端配置；页面不会伪造书目、章节或官方日期。资料未提供时显示空选择/空数据。参考书章节编号按课程提供值填写；契约没有章节列表接口，前端没有杜撰额外接口。

## 配置独立后端连接

复制 `.env.example` 为 `.env.local` 后按实际后端地址配置：

```dotenv
VITE_APP_MODE=demo
VITE_API_BASE=/api/v1
API_PROXY_TARGET=http://127.0.0.1:8080
```

Vite本地代理保留完整 `/api/v1` 路径；需要默认真实模式时将VITE_APP_MODE设为live。所有VITE_变量会进入浏览器，不得保存任何密码、供应商密钥或数据库配置。浏览器凭据仅由HttpOnly Cookie携带，不读取或保存会话Cookie。

## 模块覆盖

| 模块               | 路由                    | 真实模式的学习操作                                               |
| ------------------ | ----------------------- | ---------------------------------------------------------------- |
| M01 数字人陪伴督学 | `/companion`            | 形象/模式/声音/提醒设置，文字或语音互动，打卡与督学状态          |
| M02 择校专业分析   | `/schools`              | 条件查询、推荐、历史指标、2至4校对比、概率与风险评估             |
| M03 公共课辅导     | `/public-courses`       | 知识体系、分层讲解、考点、英语/政治/数学专项反馈                 |
| M04 专业课支持     | `/professional-courses` | 学科配置、参考书与知识体系、历年真题讲解、考点预测               |
| M05 AI答疑         | `/qa`                   | 会话、多轮追问、上传识别题目、人工核对、消息查询与取消           |
| M06 刷题错题专项   | `/practice`             | 日练/周测/专项、作答批改、错题历史、同类题与掌握进度             |
| M07 个性化规划     | `/planning`             | 本人档案、候选计划、任务调整、确认生效、动态调整与进度           |
| M08 模考估分       | `/exams`                | 试卷、服务端截止倒计时、自动保存与恢复、交卷、成绩/排名/估分     |
| M09 复试训练       | `/interview`            | 专业/英语/压力模拟、文字或上传录音回答、总结、自我介绍批改与礼仪 |
| M10 学习仪表盘     | `/dashboard`            | 学习事实、时长/正确率/专注度、曲线、雷达与周报                   |
| M11 资讯政策       | `/news`                 | 通知、政策差异、关注范围、核验日期和已读通知                     |

拍照答疑的识别文本必须人工核对后发送，只展示思路与方法；练习和模考试题在提交前没有正确答案。无样本指标显示暂无数据，未评分总分和无资料录取概率不会伪造为0。复试同意默认不勾选，录音/语音输入由用户主动操作；停止和离开页面会清理采集、播放、事件订阅和请求。

## 校验与独立构建

```powershell
npm run typecheck
npm run format:check
npm test
npm run build
npm run test:e2e
```

浏览器测试使用本机Edge，涵盖桌面与手机的演示/真实模式。真实模式测试拦截所有API并使用合成契约数据，不访问实际后端或AI。具体结果见 `docs/前端审查与本地验证.md`。

`npm run build` 独立生成dist，不需要Java、Maven或后端目录。已启动开发服务时，另一个PowerShell终端运行浏览器测试前可设置 `$env:PLAYWRIGHT_EXTERNAL_SERVER='1'`。未启动时Playwright配置会自行启动服务。

契约更新后可使用可选生成工具：`npm run contract:generate`（需Python 3），之后运行格式化、类型检查与测试。生成器仅同步类型与运行时Schema，不新增接口、不实现后端。
