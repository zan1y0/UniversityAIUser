# 前端审查与本地验证

日期：2026-10-13。项目：桌面 UniversityAIUserPage，与用户当前 VS Code 工作区一致。

## 依据与范围

原始课程要求的11个模块，原文.doc与已提取源文档的SHA256一致；接口以Apifox API契约v1.0.0为准。保留原始11模块演示页面，为真实模式实现契约学习操作面板。没有改动后端业务、OpenAPI契约或Nginx/Dockerfile，也没有执行部署。

## 发现与修复

1. 原前端仍调用旧/api接口、兼容数字成功码且部分真实模块只有未接入提示。已迁移至/api/v1，生成81个操作类型及216个Schema类型，按契约渲染功能表单与学习结果。
2. 登录仍限定手机号且使用旧CSRF Cookie名称。改为loginName/password，先获取CSRF并发送X-CSRF-Token，Cookie由浏览器credentials=include携带，刷新时通过本人档案恢复会话，退出调用正式204接口。
3. HTTP错误原先丢失业务错误信息。保留code、message、traceId及HTTP状态；校验字段、必填、枚举、范围、条件分支、未知字段和服务返回结构；取消与超时单独处理。
4. 增加图片上传→识别→人工确认→答疑流程、多轮上下文版本、私有附件读取、异步任务与SSE；拍照题不给最终答案字段；停止按最新消息版本取消，晚到增量不混入其他任务。
5. 补齐练习作答/错题、候选计划确认/调整、模考自动保存/恢复/交卷/评分显示、公共课专项、复试与资讯等正式操作。幂等重试保持原键与请求体，版本冲突不自动覆盖。
6. 修复题目内容覆盖科目下拉框、输入分支切换残留、选项编号显示、禁用浏览器存储时启动异常、交卷后仍显示倒计时并允许编辑等问题。复试同意默认不勾选；英语模式同步交流语言。数字人按返回动作展示动画，尊重系统减少动画设置。
