# 数字人聊天接入

本次修改位于 `D:\STUDY\UniversityAIUser\frontend`，直接通过 Codex 的 PowerShell 终端编辑与验证，没有操作 IDEA 或 VS Code 界面，也没有修改桌面上的独立前端副本。

## 调用流程

真实模式下，数字人页面展示陪伴聊天窗口。`ChatPanel.vue` 的陪伴督学分支调用 `backend.avatarChat()`，通过契约操作 `op014` 提交 `POST /api/v1/avatar/interactions`，请求为 `{ text, contextId }`。每次提交生成独立的幂等键，同一对话复用 contextId，点击新对话后生成新的 contextId。

接口返回 202 任务信息后，复用 `waitJob()` 查询 `GET /api/v1/jobs/{jobId}`，完成后展示 `avatarInteraction.text`。统一请求层携带登录 Cookie、CSRF Token 和 Idempotency-Key，并校验请求及响应契约。模型服务失败时显示后端错误，不回退演示回复。点击停止只停止浏览器等待，不承诺取消已提交的服务器任务。

近期对话由浏览器随当前问题发送，组合内容限制为 4000 字符并优先保留当前问题；contextId 本身不代表后端已经实现持久化对话记忆。演示模式仍使用标注的模板回复，其他模块保留原答疑调用。本次未新增模式偏好同步、语音合成或口型动画。

## 本地运行

1. 在 IDEA 打开项目根目录，给后端启动配置设置 `AI_LLM_BASE_URL`、`AI_LLM_API_KEY`、`AI_LLM_MODEL`，启动 Spring Boot，默认端口 8080。`.env.example` 不会被 Spring Boot 自动读取。
2. 在 VS Code 打开本项目的 `frontend` 文件夹，在终端运行 `npm run dev`。Vite 默认将 `/api/v1` 代理到 `http://127.0.0.1:8080`，不同后端地址可在前端 `.env.local` 设置 `API_PROXY_TARGET`。
3. 打开 `http://127.0.0.1:5173`，登录真实服务，进入“数字人陪伴督学”，发送文字。模型凭据只能配置在后端，不要写入 `VITE_` 变量。

## 验证命令

在 `frontend` 目录执行：

```powershell
npm run test
npm run build
npx playwright test tests/e2e/avatar-chat.spec.ts
```

单元测试与浏览器测试使用明确的模拟服务验证接口集成，不产生真实模型费用；真实模型回复仍需配置自己的服务后联调。
